* Validation with real files and an independent decoder

The scripts in =scripts/= are development tools and need Python with
=rawpy= (LibRaw), =numpy=, =tifffile= and =imageio=:

#+begin_src sh
python3 -m venv .venv && .venv/bin/pip install rawpy numpy tifffile imageio
#+end_src

1. =scripts/raw2dng.py in.cr2 in.dng [<|>]= makes a CFA DNG from a camera raw
   file (LibRaw decodes, tifffile writes; =>= writes big-endian).
2. =build/spectrallab in.dng out.dng=
3. =scripts/libraw_check.py out.dng= decodes the output with LibRaw and
   renders a neutral PNG for inspection.

Results of 2026-09-30 with the Rob Shea IR samples are in
[[file:overview.org][the overview]]. Additional checks made:

- LibRaw decodes the lossless JPEG output bit-identically to the
  uncompressed output (validates the encoder independently).
- The big-endian DNG produced by tifffile is read correctly.
- X-Trans input is rejected with a clear message.

Sample raw files are not part of the repository (size, copyright); they can
be downloaded from https://www.robsheaphotography.com/download/infrared-sample-raw-images/.
